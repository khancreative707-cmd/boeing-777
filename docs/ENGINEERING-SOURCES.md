# GE90–115B source record

Primary public page: https://www.geaerospace.com/commercial/aircraft-engines/ge90

The page's **GE90 Engine Model Comparison** has separate -94B and -115B columns. The -115B column states:

| Item | Public value |
| --- | --- |
| Fan / compressor stages | 1 / 4 / 9 |
| Low-pressure / high-pressure turbine stages | 6 / 2 |
| Maximum engine diameter | 135 inches |
| Engine length | 287 inches |
| Max power at sea level | 115,300 (pounds-force scale) |
| Overall pressure ratio at max power | 42 |

The page also describes composite fan blades, advances to compressor/combustor/turbine components, and the Boeing 777–200LR, 777–300ER and 777 Freighter applications. The implementation uses the -115B stage architecture. It does not use the -94B's 1/3/10 compression layout and does not use GE9X architecture.

Public photograph consulted for the swept fan, spinner, containment ring and overall appearance:
https://www.geaerospace.com/sites/default/files/2023-12/ge90-115b-engine.jpg

The project reference supplies **22 fan blades** and **128 inches of fan diameter**. These two values are used as construction constraints; the above page's textual specification table does not list them. The table's maximum engine diameter must not be mistaken for the fan diameter. Only the fan diameter is dimensionally referenced in the procedural geometry; the table's complete engine length, proprietary internal clearances and detailed casing proportions are not reproduced as exact dimensions.

Public-source access originally returned a proxy 403. After the environment/network update, the page and photograph downloaded successfully with TLS verification intact and were inspected. The network draft includes the official GE domains for future research.

All non-fan airfoil counts, dimensions, attachment shapes, fuel-nozzle arrangement, liner perforations, accessory routes, bearing layout and maintenance/removal sequence are educational approximations. No proprietary CAD or certification/maintenance data is claimed.
